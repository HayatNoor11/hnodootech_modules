Hn Top Selling Items of the Month
=================================

This module provides a report for the top-selling products of the current month in PDF format. It helps in sales performance analysis and stock planning.

Key Features
------------
- Monthly sales summary of top products
- PDF report export
- Easy-to-use wizard to select number of top items

Usage
-----
1. Go to **Sales > Reporting > Top Selling Items**.
2. Use the wizard to specify how many top items to include.
3. Generate and download the PDF report.
